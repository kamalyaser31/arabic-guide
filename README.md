# دليل التحرير والصياغة العربية للنماذج اللغوية
### Arabic Style & System Prompt Guide for LLMs

دليل مرجعي مكثف مُصمم لتوجيه نماذج الذكاء الاصطناعي نحو إنتاج نصوص عربية فصيحة رصينة، مجردة من الأساليب المترجمة والركاكة التحريرية.

---

## مصدر البيانات

تُمثّل هذه المادة استخلاصاً علمياً وتجريداً تحريرياً للمحتوى اللغوي الوارد في [دليل التحرير العربي لأرامكو السعودية - الإصدار الثالث](https://www.aramco.com/-/media/publications/books/arabic_style-guide-v-3.pdf)، وقد جرت معالجته عبر ثلاث عمليات:

1. **التجريد:** تحويل الأمثلة من سياقات مؤسسية خاصة إلى صياغات عامة.
2. **التصفية:** إسقاط الأحكام البدهية التي تُتقنها النماذج اللغوية أصالةً لتجنب الحشو.
3. **إعادة الهيكلة:** صياغة القواعد في قالب تعليمات نظام (System Prompts) وجداول محكمة.

---

## دوافع المشروع

تعاني المخرجات العربية لنماذج الذكاء الاصطناعي من استنساخ البنى التركيبية للغات الأجنبية وإقحام الروابط وتكرار الألفاظ، فضلاً عن أخطاء تحريرية شائعة تُضعف سبك النص. يُمثّل هذا المستودع قاعدة معرفية تتميز بـ:

- **ارتفاع الكثافة الدلالية:** لا شروح بدهية، كل سطر يُضيف قيمة.
- **المباشرة:** ضوابط أسلوبية وجداول تفصيلية قابلة للتطبيق الفوري.
